# Import/Export QA fixtures – WIP 11

קבצי בדיקה ידניים/אינטגרטיביים למסך ייבוא Excel. בכל קובץ קיימות בכוונה שורות תקינות, כפילויות ושורות שצריכות להיכשל ב-Validation.

- `clients_import_qa.xlsx` – כפילות לפי קוד לקוח, כפילות בתוך הקובץ ושעות ריטיינר שליליות.
- `employees_import_qa.xlsx` – כפילות מספר עובד ואחוז משרה לא חוקי.
- `absences_import_qa.xlsx` – כפילות רשומה, טווח תאריכים הפוך ועובד לא קיים.
- `tasks_import_qa.xlsx` – מזהה משימה כפול, דמיון חכם בין שורות, Deadline לפני Planned End ולקוח לא קיים.

בבדיקת UI יש לוודא Preview לפני Commit, בחירה `ייבא/דלג/עדכן`, שאין אפשרות `עדכן` לכפילות שמקורה בשורה אחרת באותו קובץ, וששגיאה באחת השורות אינה נשמרת בשקט.
